# Dungeon Defenders Progression Hub

A fan-made Dungeon Defenders 1 guide website focused on progression, achievement routing, and 100% completion tracking.

Live site: https://rebeljakefang.github.io/dd1-progression-optimizer-/

## About the Project

The Dungeon Defenders Progression Hub is designed to help players move through Dungeon Defenders 1 more efficiently. It includes progression guidance, completion routes, achievement explanations, useful resources, and a checklist for tracking long-term goals.

The site is organized around helping players answer questions like:

- What should I farm next?
- What maps should I clear for progression?
- What achievements count toward 100% completion?
- What pets, challenges, survival maps, and Lost Quest maps do I still need?
- How do I work toward Ultimate Defender and Eternal Defender?

## Pages

### Home

The main landing page for the site. It links to the major guide sections and the Dungeon Defenders Build Planner.

### Progression Guide

A step-by-step progression route based on community knowledge and Chiku’s guide structure. This page helps players move from early game into stronger farming and achievement cleanup.

### 100% Completion Guide

A readable guide explaining the best order to approach completion goals, including campaign achievements, basic achievements, challenges, survival, pets, Shards content, Summoner achievements, Ultimate Defender, Eternal Defender, Ruthless Defender, and extra cleanup.

### 100% Completion Checklist

A tracking page with checkboxes for major achievement groups. It includes tables for multi-step goals like pets, survival, challenges, Shards, and Lost Quest maps.

### Useful Info

A resource page for extra tips, links, setup help, hotkeys, and other Dungeon Defenders information.

## Project Goals

The goal of this project is to make Dungeon Defenders 1 progression and completion easier to understand by combining guide information, route planning, and checklist tracking into one website.

Future improvements may include:

- Saving checklist progress with JavaScript and local storage
- More detailed map-specific strategies
- Better achievement filtering
- More pet drop details
- More links to build planners and community resources
- Possible save-file parsing or progression optimizer tools
