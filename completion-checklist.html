How to Use This Checklist

Use this page while playing to track the major Dungeon Defenders completion achievements. Large achievements with multiple parts are split into tables so each required step can be checked off.

Master Checkbox Feature

Big achievement checkboxes can check connected items automatically. For example, clicking Catch 'em All checks the pet rows, and clicking Eternal Defender checks the Lost Quest map rows.
